# Online Chat Messenger - Stage 1

## 概要

PythonのUDPソケットを使用して作成した、CLI形式のチャットアプリケーションです。

クライアントがサーバーへメッセージを送信すると、サーバーに登録されている送信元以外のクライアントへメッセージを配信します。

## 主な機能

* UDPによるメッセージの送受信
* 複数クライアント間でのメッセージ配信
* ユーザー名とメッセージを含む独自プロトコル
* 送信と受信の同時処理
* 一定時間メッセージを送信していないクライアントの自動削除
* `Ctrl + C`によるプログラムの終了

## 使用技術

* Python 3
* UDPソケット
* Python標準ライブラリ（`socket`、`threading`、`time`、`selectors`）

```text
.
```

* `client.py`: メッセージの送受信を行うCLIクライアント
* `server.py`: クライアントの管理とメッセージの配信を行うサーバー
* `protocol.py`: メッセージのエンコードとデコードを行うモジュール
* `load_test.py`: 複数のUDPクライアントを使用して負荷テストを行うスクリプト

## メッセージプロトコル

メッセージは、次の形式でバイト列に変換して送信します。

```text
[ユーザー名のバイト数: 1 byte][ユーザー名][メッセージ本文]
```

ユーザー名とメッセージ本文は、UTF-8でエンコードされます。

ユーザー名のバイト数は1バイトで表現するため、ユーザー名の最大サイズは255バイトです。

## 実行方法

### 1. リポジトリを取得する

次のコマンドを実行して、リポジトリを取得します。

```bash
git clone git@github.com:tsuyoshikojima/online-chat-messenger.git
cd online-chat-messenger/stage1
```

すでにリポジトリを取得している場合は、`stage1`ディレクトリへ移動してください。

### 2. サーバーを起動する

ターミナルを開き、`stage1`ディレクトリで次のコマンドを実行します。

```bash
python3 server.py
```

サーバーは、デフォルトで次のアドレスとUDPポート`9001`を使用してメッセージを待ち受けます。

```text
Bind address: 0.0.0.0
Port: 9001
```

サーバーを起動したターミナルは、そのまま開いておいてください。

### 3. クライアントを起動する

サーバーとは別のターミナルを開き、`stage1`ディレクトリで次のコマンドを実行します。

```bash
python3 client.py
```

クライアントの起動後、画面の案内に従ってユーザー名を入力します。

複数のクライアントでチャットする場合は、クライアントごとに別のターミナルを開き、同じコマンドを実行してください。

例として、次のようにターミナルを3つ使用します。

```text
ターミナル1: サーバー
ターミナル2: クライアントA
ターミナル3: クライアントB
```

### 4. ユーザー名を入力する

クライアント画面でユーザー名を入力し、Enterキーを押します。

```text
ユーザー名を入力してください。
> Ken
```

### 5. メッセージを送信する

クライアントの画面でメッセージを入力し、Enterキーを押します。

送信されたメッセージは、サーバーに登録されている送信元以外のクライアントへ配信されます。

```text
メッセージを入力してください
> Hello
```

受信側のクライアントには、送信者のユーザー名とメッセージが表示されます。

```text
メッセージを受信しました。
ユーザー: Ken
内容: Hello
```

### 6. プログラムを終了する

サーバーまたはクライアントを終了する場合は、それぞれのターミナルで`Ctrl + C`を押してください。

## クライアント管理とタイムアウト

サーバーは、メッセージを送信してきたクライアントのIPアドレス、ポート番号、最終通信時刻を管理します。

一定時間メッセージを送信していないクライアントは、登録済みクライアントの一覧から削除されます。

現在のタイムアウト時間は30秒です。

## 動作確認

以下の動作を確認しています。

* 複数クライアントからのメッセージ送信
* 他のクライアントへのメッセージ配信
* 日本語メッセージの送受信
* 不正なメッセージを受信した場合のエラー処理
* タイムアウトしたクライアントの削除
* `Ctrl + C`による終了

### 負荷テスト

1,000クライアントをサーバーに登録し、そのうち1クライアントから10件のメッセージを送信するテストを実施しました。

各メッセージは、送信元を除く999クライアントへ配信されます。

```text
10メッセージ × 999受信先
= 9,990件
```

テスト結果は次のとおりです。

* 期待受信数: 9,990件
* 実際の受信数: 9,990件
* 未受信数: 0件

## 制限事項

* UDPを使用しているため、メッセージの到着や到着順序は保証されません。
* サーバーを終了すると、登録されていたクライアント情報は失われます。
* ユーザー認証やメッセージの暗号化は実装していません。
* 現在は同一PCまたはローカルネットワーク内での利用を想定しています。
